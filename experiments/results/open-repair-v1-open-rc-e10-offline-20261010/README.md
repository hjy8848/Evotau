# Intermediate Synthetic fixture — not a research result

This is the first offline control-flow fixture, frozen at implementation commit
6dacae17c094a181e21401d56e0e5c285b109dd2. It used Fake Providers/Runner and made zero
real API calls. Toy E3/V1 IDs are not the Airline E10 template's measured tasks.

It predates persisted Open candidate-program history and physical Synthetic trajectory
files. Its in-memory messages, hashes, Trial indexes and journals are retained for
engineering audit only. Use the separately frozen `-final` directory for final
verification. No historical or native benchmark scores were imported or overwritten.
